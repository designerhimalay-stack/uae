Typical engagements

What a SharePoint project looks like in our industries.

How the work usually runs, starting with one team or one process.

Insurance: policy and claims records

Policy and claims documents often sit across file shares and email. We move one department to SharePoint with metadata, retention, and permissions, then migrate the rest in waves.

What changes

  • Documents found by policy or claim
  • Retention applied by rule
  • Access controlled by role

Oil and gas: procedures and permits

Procedures, permits, and asset documents are often scattered across sites. We build a SharePoint document centre for one asset, with version control and approval workflows.

What changes

  • One current version of each procedure
  • Approvals with an audit trail
  • Documents reachable from site

Engineering and construction: drawings

Contractors often lose time looking for the latest drawings and transmittals. We set up SharePoint project sites with a standard structure, piloted on one project.

What changes

  • The latest drawing, every time
  • A standard site for each project
  • Partners given the access they need
